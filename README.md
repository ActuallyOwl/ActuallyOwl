## 🚀 Featured Projects

### 🍜 [FuudGo — Food Ordering System](https://github.com/ActuallyOwl/fuudgo-os)

A full-stack food-ordering application built around sample restaurants in Kuching.

| Layer | Technologies / role |
| --- | --- |
| Customer application | Next.js App Router, React, TypeScript |
| API | Laravel REST API |
| Database | MariaDB / MySQL |
| Authentication | Laravel Sanctum stateful sessions and CSRF protection |

**What it includes**

- Restaurant and menu browsing, with sample listings and menu modifiers.
- Guest basket saved in browser storage, plus customer accounts, addresses, and order history.
- Server-side checkout that checks current prices, modifiers, delivery fees, and promotions.
- Cash-on-delivery and cash-on-pickup order flows with order-status history.
- Role-protected admin pages for core restaurant, menu, order, promotion, and settings tasks.

**Project status:** A substantial learning project with a local development setup documented in its README. Online payments, production email delivery, and production deployment are not configured.

### 📍 [Location App](https://github.com/ActuallyOwl/location-app)

A small browser geolocation prototype built with HTML, CSS, and JavaScript. After the visitor grants browser location permission, it reverse-geocodes the coordinates with OpenStreetMap Nominatim and displays a map link.

**Data flow:** The current prototype also sends the retrieved coordinates and address to a configured Google Apps Script endpoint. This should be made clear to users and reviewed before using the app with anyone else's location.
